## Pasos realizados

1. Se creó un repositorio local.
2. Se creó el archivo index.html y README.md.
3. Se realizó el primer commit en la rama master.
4. Se creó la rama feature/navbar para desarrollar una nueva funcionalidad.
5. Se agregó una barra de navegación en index.html.
6. Se realizó commit en la rama feature/navbar.
7. Se fusionó la rama feature/navbar con master utilizando git merge.
8. Se subieron ambas ramas al repositorio remoto en GitHub.

## Ramas utilizadas
- master
- feature/navbar

## Resultado
Se implementó correctamente una barra de navegación simulando un flujo de trabajo colaborativo.
